🐕 BAYMAX — The Mad Dog

Welcome to the official source files repository for BAYMAX — The Mad Dog, 
a step-by-step course on creating a retro PS1-style horror game from scratch in Unity.

🎮 Play Fractured Psyche — my other retro horror game:
https://batpan.itch.io/fractured-psyche


📚 About the Course
In this course, we are building BAYMAX — The Mad Dog from the ground up.
The goal is to take the game from a brand-new Unity project all the way to a finished game published on itch.io.
This repository contains the source files and scripts used throughout the course.

📂 Repository Structure
Files are organized according to the corresponding course part:

BAYMAX---The-Mad-Dog-
│
├── Part 1/
├── Part 2/
├── Part 3/
└── ...

🔎 Each part contains the files created or used during that section of the course.
Note: This repository does not contain the complete Unity project or all third-party assets. 
Large assets, models, textures, audio, and third-party packages may be provided separately or 
linked from their original sources.
